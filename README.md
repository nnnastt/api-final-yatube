# API Yatube

Социальная сеть для публикации постов с возможностью комментирования и подписки на авторов.

## Описание

API Yatube предоставляет возможности:
- Создание, редактирование и удаление постов
- Добавление комментариев к постам
- Подписка на других пользователей
- Просмотр ленты постов
- Поиск по подпискам


Проект построен на Django REST Framework с использованием JWT-аутентификации.

## Технологии

- Python 3.9+
- Django 3.2
- Django REST Framework 3.12
- JWT-аутентификация (djangorestframework-simplejwt)
- SQLite (разработка) / PostgreSQL (продакшн)
- Pillow (обработка изображений)
